اولین انتشار عمومی آزمایشی **My Screen Mirror** برای Android Auto؛ هدف آزمایش تیگو ۷ PHEV است.

APK همان نسخهٔ محلی نصب‌شده است؛ این انتشار تغییر عملکردی جدید ندارد.

- میرور کل نمایشگر گوشی، سه کیفیت و انتخاب حفظ تصویر/پرکردن قاب.
- لمس و کشیدن، خانه/برگشت با مجوز اختیاری Accessibility.
- درخواست افقی شدن و تلاش برای بازگردانی تنظیم چرخش با اجازهٔ اختیاری تغییر تنظیمات.
- اپ فقط روی گوشی نصب می‌شود؛ تغییری روی نرم‌افزار مدیا ندارد.

**وضعیت:** نصب/اجرای اپ مستقل و مجوزهای گوشی تأیید شده‌اند. مسیر پایهٔ تصویر در نمونهٔ قبلی آزمایش شده بود؛ لمس، چرخش و پایداری نسخهٔ مستقل هنوز منتظر تست واقعی‌اند. فقط در خودروی متوقف آزمایش کنید.

برای ظاهرشدن در لانچر Android Auto، نصب عادی APK ممکن است کافی نباشد؛ بخش نصب README را بخوانید. Single application در این نسخه به‌دلیل درخواست کل صفحه غیرفعال است. محافظت محتوای حساس/DRM دور زده نمی‌شود و capture صوت مستقل وجود ندارد.

فایل با کلید توسعهٔ خصوصی محلی امضا شده؛ این کلید منتشر نشده است. برای به‌روزرسانی مستقیم، نسخه‌های بعدی باید همان بسته و امضا را حفظ کنند.
